# Proyecto de apoyo a ventas para personas con discapacidad

Una primera versión de un programa sencillo desarrollado en Python para facilitar procesos de venta y organización de productos, pensado como herramienta accesible y práctica para personas con discapacidad que desean vender de manera más autónoma.

## Descripción PCD

Este proyecto busca crear una solución básica para PCD:

- registrar productos
- calcular precios y totales
- gestionar ventas simples
- facilitar la atención al cliente con una interfaz clara
- apoyar la operación diaria de pequeñas ventas con un enfoque accesible

La idea es que sea una base útil para empezar un sistema de ventas amigable, fácil de entender y adaptable a distintos contextos.

## Objetivo

Desarrollar una aplicación en Python que permita:

- organizar inventario básico
- registrar ventas rápidas
- mostrar información de manera clara
- ahorrar tiempo en procesos manuales
- ofrecer una herramienta accesible para personas con necesidades específicas

## Características principales

- interfaz de consola simple y fácil de usar
- registro de productos con nombre y precio
- listado de productos disponibles
- cálculo automático del total de la compra
- gestión básica de ventas
- estructura simple para ampliar funcionalidades más adelante

## Tecnologías utilizadas

- Python 3
- programación orientada a objetos (opcional para futuras versiones)
- consola / entrada y salida básica

## Requisitos

- Python 3.8 o superior
- editor de código o terminal

Al iniciar la aplicación, el usuario podrá:
